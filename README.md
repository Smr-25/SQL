# 📖 About The Repository

**SQLTasks** is a curated collection of SQL exercises and mini-database scenarios created to practice:

- Relational database design
- DDL/DML fundamentals
- Joins, aggregations, and subqueries
- Constraints and data integrity
- Stored procedures and basic querying patterns

This repository serves as a structured SQL learning portfolio with practical scripts and sample data.

---

# 🧩 Repository Structure

Each folder contains independent SQL scripts and, where available, ERD/diagram images to visualize schemas.

## Included Projects

| Project | Description |
|---|---|
| `MarketDB` | Product and employee tables with CRUD and constraints practice |
| `IMDb` | Movie database schema with relationships and query tasks |
| `RestoranDB` | Restaurant orders schema with joins and aggregations |
| `SQLQueryLab` | Mixed SQL lab tasks (e.g., HospitalDB procedures) |
| `SQLQueryTask` | Intro SQL tasks and basic schema edits |
| `Spotify` | Music platform schema (includes ERD image) |
| `TurboAz` | Car marketplace schema with queries and ERD image |

> Some folders include ERD images (`DBDesigner.jpg`) for schema visualization.

# ⚙️ Prerequisites

Before running the scripts, make sure you have:

- SQL Server (LocalDB or full instance)
- SQL Server Management Studio (SSMS) or Azure Data Studio

---

# ▶️ Running The Scripts

1. Open any `.sql` file in SSMS or Azure Data Studio.
2. Execute the script top-to-bottom to create the database, tables, and sample data.
3. Run the query sections to verify results.

---

# 🌱 Recommended Workflow

```text
1. Pick a folder
2. Review the schema/ERD (if provided)
3. Run the SQL script
4. Modify or extend the queries
5. Practice additional tasks
```
